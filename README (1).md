# READS Knowledge Tracing Studio

Neutral, domain-agnostic interactive dashboard for Bayesian knowledge tracing.

## Files to upload

Upload the project preserving this structure:

```text
index.html
css/styles.css
js/config.js
js/math.js
js/model.js
js/charts.js
js/app.js
.nojekyll
.github/workflows/pages.yml
README.md
```

## GitHub Pages

In the repository:

1. Open **Settings → Pages**.
2. Set **Build and deployment → Source** to **GitHub Actions**.
3. Push to `main`.
4. The included Pages workflow will publish the site.

No build step or external dependencies are required.
